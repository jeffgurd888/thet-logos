The Bench, Replayed: What the Search Cost, What the Checking Cost

A replay of this lab's own bench record, 2026-10-29 to the freeze point at the SHELF-2 landing (census 10,224 strict / 345 modules): every landing, partial, kill, and probe the coordinator log recorded, drawn in episode space — bench time, search cost, check cost, yield. Nothing here is a view inside any proof checker. There is no such view to show (see the fence block).

NO CLAIM. This page proves nothing, tests nothing, and moves no dial. P vs NP: NO CLAIM, parts 0. The one bounded sentence this page is allowed is this: Recognition is cheap here and construction is expensive — that asymmetry, as one bench lived it, is all that is shown. This bench's job counts and seconds are one proof-assistant workflow's economics; they are not a complexity measure, and nothing on this page is evidence about any Clay problem, any instance, or any algorithm.
Registry rule. Anything "seen" on this page is Tier 5 until the Sky Registry pre-registers it and checks it. This page pre-registers nothing. Panel A — The event spine under the named projection P(θ)

Records T1-grade · rendering exhibit-grade · ring glyph T5 metaphor

The projection, named on the panel. Each event is a point of the episode space (u₁ search cost, u₂ check cost, u₃ yield, u₄ bench time) — coordinates drawn only from the record. The display is the map P(θ) : (u₁, u₂, u₃, u₄) → page: horizontal position = u₄ (bench time, UTC); vertical position = v(θ) = ŷ·cos θ + ẑ·sin θ, where ŷ = log₁₀(1 + u₁) / 4 (search jobs, log-scaled — a display choice, printed here) and ẑ = min(u₃, 120) / 120 (strict declarations landed); θ = 0 by default, adjustable below. Color law (Jeff's law, a named design choice, not a discovered correspondence): X red = search (u₁ intensity), Y blue = check (u₂ — a standard-three axiom verdict on record), Z green = yield (u₃). Glyph size carries u₂: events with a recorded axiom check are larger and carry a ring. The ring at a check event is a T5 metaphor for recognition — a check event is not two systems with gap sets, and no shared gap is computed or claimed here; the literal resonance panel is gated on the RES line and is not built on this page. Kills sit at u₃ = 0 with their own marker — zero yield, full information, never made invisible. Events whose job count was not recorded sit on the baseline: not recorded is not zero. Between events, bench time is drawn as gap — never filled (K-KV-FILL).
