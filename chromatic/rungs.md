# The 10 rungs — detailed

Source: Gurd, *The Ontological Thet–LOGOS Framework* (Revised Draft, Nexus
Research, Sept 2026), §2.1. **The ladder is an organizational/mnemonic
device, not a formalized Möbius-bundle construction.** Tiers refer to the
framework's five-tier ledger (see `../epistemic-ledger/TIERS.md`).

---

## Rung 1 — Void (∅) · Black · T1

*Proto-Linguistic Void.* Assumed absolute logical origin: absence of
metric tensors, background coordinates, particle excitations. Listed among
the assumed primitives (Framework Def. 1.1). **T1 — Assumed Primitive.**

## Rung 2 — Distinction ⟨a,b,c⟩ = ab†c · Cobalt · T2/T3

Primary activation via the ternary product. Provides a minimal
three-point context for observation: *contextual measurement of c via a
and b* (Framework Table 1, §2.1.2). Product definition **T2**;
associativity on models **T3**. See `../axioms/TRO-axioms.md`.

## Rung 3 — Thet Primitive Θ = (θ, θ†) · Purple · T1

Forward projection `y = θx`; `θ†` its adjoint (Framework Def. 1.2).
Incorporates a **five-step nilpotent ladder as a working hypothesis**
(Framework §2.1.3) — hypothesis, not theorem. **T1 — Assumed Primitive.**

## Rung 4 — LOGOS Engine K = −log ∆ · Crimson · T2/T3

Cyclic, self-referential operator engine generated by circulation of
Thet distinctions (Framework Def. 1.3). Associated with thermal time via
the Tomita–Takesaki modular Hamiltonian `K = −log ∆`:

```
σ_s(X) = e^{isK} X e^{−isK},      KMS equilibrium
```

Adjoint reflection into the conjugate algebra via the real structure J.
Definitions **T2**; flow group property and KMS cyclicity **T3**
(numerical). See `../spectral/modular-flow.md`.

## Rung 5 — Tripotent Variety N₀³ = N₀ · Amber · T1/T5

Reference element `N₀ ∈ M₂(ℝ)` satisfying `N₀³ = N₀` (Framework §2.1.5,
Table 1). Existence **T1**.

> **Caveat (T5 — Withdrawn).** The earlier claim that the linearization
> `L(X) = X + N₀XN₀` yields `dim ker L = 4`, thereby fixing spacetime
> dimension, is **withdrawn** as inconsistent on `M₂(ℝ)`: a
> four-dimensional kernel would force `L ≡ 0`, implying `N₀ = −I`,
> contradicting the tripotent relation unless `N₀ = 0`. The correct
> geometric meaning of `N₀`, if any, remains an open question.

See `../algebra/tripotent-N0.md`.

## Rung 6 — 32-State Spectrum H_F = ℂ³² · Magenta · T2/T3/T5

Finite gauge algebra `A_F = ℂ ⊕ ℍ ⊕ M₃(ℂ)` acting on

```
H_F = H_L ⊕ H_R ⊕ H_L^c ⊕ H_R^c = ℂ⁸ ⊕ ℂ⁸ ⊕ ℂ⁸ ⊕ ℂ⁸
```

the standard one-generation finite space of the
Connes–Chamseddine–Marcolli construction, including a right-handed
neutrino and charge conjugates (Framework §2.1.6). Space and
representations **T2**; KO relations **T3**.

> **One generation only.** Three generations require `ℂ⁹⁶` or
> `ℂ³² ⊗ ℂ³` with generation-mixing Yukawa matrices — **T5 (Open)**.

See `../spectral/hilbert-space-32.md`, `../spectral/gauge-algebra.md`.

## Rung 7 — Spectral Triple D_F · Cyan · T2/T3

Geometry encoded by the internal Dirac operator, the 32×32 block matrix
(Framework eq. 2):

```
        H_L   H_R   H_L^c  H_R^c
H_L   [  0     A      C      0   ]
H_R   [ A†     0      0      E†  ]
H_L^c [ C†     0      0      B   ]
H_R^c [  0     E      B†     0   ]
```

Self-adjoint, γ_F-odd; KO relation `J_F D_F = D_F J_F` conditional on
block symmetries. Definition **T2**; self-adjointness/γ-oddness **T3**.
See `../spectral/dirac-order-one.md`.

## Rung 8 — Order Conditions · Emerald · T3/T4

Two distinct axioms of real spectral triples (Framework §2.1.8):

- **Order-zero:** `[π(a), π°(b)] = 0` — representation and opposite
  commute; uncouples matter/antimatter actions. **T3** (Lean proof +
  numerical check).
- **Order-one:** `[[D_F, π(a)], π°(b)] = 0` — first-order condition on
  the Dirac operator; constrains admissible mass matrices.
  Opposite-algebra convention: `π°(b) = Jπ(b)*J⁻¹`.

Under order-one, cross-term blocks **C and E vanish (or take restricted
forms)**, isolating the fermion mass matrices `Y_u, Y_d, Y_e, Y_ν` and a
possible Majorana matrix `Y_R`. **T4 — Emergent/Standard.**

> Framework §2.1.8, §6: *These are the standard one-generation structures
> of the literature; no new mass predictions are claimed.*

Full 576-pair machine check: **T5 (Open — "complete Lean archive")**.

## Rung 9 — Thet Engine (∆gap) · Indigo · T2(sketch)/T3(sim)/T5(device)

A **conceptual discrete state machine** that perturbs the spectral gap

```
∆ = min { |λ| ∈ spec(D_F) : |λ| > 0 }
```

(Framework §2.1.9). Realized here as the numerical engine
`../python/thet_logos/spectral_gap.py` — a **simulation (T3)**.

> **No hardware realization is asserted** (Framework §2.1.9). Any device
> claim would be Tier T5 at best; none is made. Strict rule applies:
> Theorem ≠ Simulation ≠ Experiment ≠ Device.

## Rung 10 — Epistemic Ledger · White · (meta)

Verification of mathematical statements against independent empirical
data remains future work (Framework §2.1.10). The ledger itself —
`../epistemic-ledger/` — is the tier system enforcing the separation
between mathematical consistency and empirical claim.
