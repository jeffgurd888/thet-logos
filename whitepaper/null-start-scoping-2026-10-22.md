## The idea, in the box's own language

The void of a finite Gibbs box is the **degenerate state**: all sector
energies equal. No gap, no shape, nothing distinguished — the null
start of the box. The brick proves the void is *silent*, that it is
the **only** fully silent state, and that it is **β-blind** — the
temperature of nothing is not a thing. Structure (a gap) is the first
departure, and the already-landed rungs price exactly what switches
on when it appears.

## New targets (the brick's own content)

- **T1 — Silence.** At the degenerate state, the modular Hamiltonian
  `diagModularK` is a scalar matrix; hence φ = i[K,D] = 0 for **every**
  Dirac operator D, with no hypothesis on D. (The void answers every
  probe with nothing.)
- **T2 — Uniqueness.** The void is the *only* fully silent state: if
  φ = 0 for every D, then K is a scalar, so all sector weights — hence
  all energies — are equal. (Anything with a gap speaks to some probe.)
  Route: center of the matrix algebra via matrix units, or
  FluxClassification applied sector-wise; builder's choice, verdict
  reported either way.
- **T3 — β-blindness.** At the degenerate state, separation equals the
  flat charge average at **every** β (Rung 2 proved β = 0; this is all
  β): the void has no temperature. Contrapositive companion, if it
  comes free from T2's route: any state whose separation moves with β
  carries a gap (two-sector case already in Rung 1 T3; N-sector form
  only if the proof gives it — no pin promised in advance).

## Fences

- **K-V1.** The "void" here is the degenerate Gibbs state of a finite
  box. It is not the QFT vacuum, not creation ex nihilo, not a
  cosmological initial condition. Jeff's null-start ordering (shape
  before heat) is T5 motivation, recorded on this charter — never a
  theorem statement.
- **K-V2.** No gravity object. "Shape" in this brick means the sector
  structure of a finite state, not spacetime geometry. This brick
  earns nothing toward the gravity dial and claims nothing about it.
