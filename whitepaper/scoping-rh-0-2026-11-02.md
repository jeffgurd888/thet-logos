## 4. K-RH-1 vacuity check on Shape A — PASS, one cosmetic mismatch found & fixed by adoption

1. **Genuine zero set.** The quantified function is the pin's
   analytically-continued ζ (§2.1), whose zero set is the pin's own
   `riemannZetaZeros` (ZetaZeros `:36`) — a genuine, discrete,
   nonempty set (it contains every `-2*(n+1)` by §2.3 and the
   on-line zeros). Not a junk function, not an empty domain.
2. **False instances if RH were false.** Take a hypothetical zero
   at `s = 3/4 + 100i`: premise 1 holds by hypothesis; premise 2
   holds (`re s = 3/4`, while `-2*(n+1) ≤ -2` is real, so `s` is
   of no trivial form); premise 3 holds (`s ≠ 1`); conclusion
   `s.re = 1/2` is **false**. So Shape A is falsified by exactly
   the counterexamples that would falsify RH — non-vacuous,
   not trivially satisfiable.
3. **Not trivially false / exclusion is load-bearing and correct.**
   Without premise 2 the statement would be refuted by the pin's
   own `riemannZeta_neg_two_mul_nat_add_one` (real zeros at
   re = −2, −4, … ≠ 1/2). With it, those seats — and only
   zero-seats of that form — are excluded.
4. **Junk-value seats audited.**
   - `s = 1`: the pin's junk value is `(γ - log (4π))/2 ≠ 0`
     (ZetaAsymp `:421,444`), so premise 1 already excludes the
     pole seat; premise 3 (`s ≠ 1`) is **redundant but harmless**
     — belt-and-braces in the pin's def, not a vacuity hole.
   - `s = 0`: `riemannZeta_zero : ζ 0 = -1/2 ≠ 0` (RiemannZeta
     `:151`) — excluded by premise 1. No true-by-junk seat exists
     on any seat the audit can exhibit.
5. **Mismatch report (what this check exists to catch).** One
   mismatch found, in the *pack's* draft shape, not in the pin:
   the pack (and registration sketch) wrote the trivial-zero seat
   as `s = -(2*(n+1))`, while the pin's actual trivial-zero API
   (§2.3) and the pin's RH def both use **`-2 * (n + 1)`**.
   The two are equal as values (`neg_mul`) but not the pin's
   literal form; a hand-copied pin in the pack's form would drift
   from the cited API for zero benefit. **Shape A eliminates the
   mismatch by construction** — it adopts the pin def, so the
   trivial-zero disjunct *is* the pin API's form. No mismatch
   between the pin's RH def and the pin's trivial-zero theorem.
